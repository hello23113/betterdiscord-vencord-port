# BetterDiscord Vencord Port

Ports of [Vencord](https://github.com/Vendicated/Vencord) plugins to [BetterDiscord](https://betterdiscord.app).

| Plugin | What it does | Original authors |
|---|---|---|
| MessageLogger | Keeps deleted and edited messages, with edit history. Saved across restarts. | rushii, Ven, AutumnVN, Nickyux, Kyuuhachi, sadan, f3tch (Vencord) |
| RelationshipNotifier | Tells you when a friend removes you, a friend request is cancelled, or you are removed from a server or group DM. | nick (Vencord) |
| PlatformIndicators | Shows which devices (desktop, mobile, web) a user is on. | kemo, TheSun, Nuckyz, Ven (Vencord) |
| ImageZoom | Hold left click on an opened image to zoom. Scroll to zoom, Shift + scroll to resize the lens. | Aria (Vencord) |

## Install

Download a `.plugin.js` file and put it in your BetterDiscord plugins folder (Settings → Plugins → Open Plugins Folder).
